# Design System & Token Standards

## Color Tokens
- Primary Brand: Sky Deep (`#0369A1` / `#0C4A6E`)
- Trust Emerald: `#047857` / `#10B981`
- Action LINE: `#06C755`
- Accent Warm Amber: `#F59E0B` / `#D97706`
- Surface Background: `#F8FAFC` (Clean Cream), `#FFFFFF` (Pure Card)
- Text Body: `#1E293B` (Ink 900)

## Component Patterns
1. **Elevated Glass Card**: `border border-slate-200/80 bg-white/90 shadow-[0_8px_30px_rgb(0,0,0,0.04)] backdrop-blur-xl hover:shadow-[0_12px_40px_rgb(0,0,0,0.08)] hover:-translate-y-1 transition-all duration-300`
2. **Japanese Trust Seal**: `inline-flex items-center gap-1.5 rounded-full bg-amber-500/10 border border-amber-500/20 px-3 py-1 text-xs font-bold text-amber-900`
3. **Primary CTA**: Button with high contrast, icon feedback, rounded-2xl or rounded-full, with focus rings.
